# ADR 0004: GPL-3.0-only project license

- **Status:** Accepted
- **Decision:** License Voxora under GNU GPL version 3 only, expressed as SPDX `GPL-3.0-only`, with the canonical unmodified text in `LICENSE`.
- **Why:** Preserve copyleft freedoms with a precise, fixed version expression and transparent source obligations.
- **Rejected alternatives:** `GPL-3.0-or-later`; permissive relicensing; copying or deriving implementation from another GPL/AGPL project.
- **Consequences:** Every dependency, native component, asset, provider SDK, framework, and model is reviewed independently. GPL-3.0-only is project policy, not an approval of any future artifact.
